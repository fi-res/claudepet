# Clawd — десктопный питомец

Пиксельный Claude, который живёт поверх рабочего стола (Windows / Linux).
Порт плагина `clawd_pet` для exteraGram/AyuGram на Rust + Tauri 2.
Внешний вид и цвета — как у логотипа Clawd в Claude Code CLI.

Сейчас Clawd умеет:

- гулять по низу экрана (прямо по панели задач), моргать, махать, подпрыгивать, болтать;
- следить глазами за курсором и радоваться, когда курсор на нём;
- **клик** — ойкнуть, **двойной клик** — прыжок, **много кликов** — обидеться;
- **удержание** — гладить (води мышью туда-сюда — летят сердечки);
- **перетаскивание** и **бросок** — летит, отскакивает от краёв, может закружиться голова;
- если подбросить к верхнему краю — повиснет на руках и сорвётся;
- сам находит себе занятия: **читает** книжку (бегает глазами по строчкам, листает страницы),
  **программирует** за ноутбуком (печатает, ловит баги), **думает** со спиннером как в Claude Code
  и выдаёт идею, иногда **дремлет** в ночном колпаке и просыпается сам;
- если отвлечь его кликом посреди занятия — возмутится;
- **слышит звук компьютера**: резкий громкий звук будит спящего Clawd (а бодрствующего заставляет
  вздрогнуть), а когда играет музыка — надевает наушники (и продолжает читать/кодить в них)
  или танцует в такт битам;
- засыпает, если его долго не трогать, и спит не дольше 20–40 минут; просыпается от музыки,
  громкого звука, курсора на нём или когда ты возвращаешься к компьютеру после отлучки.

- **дружит с Claude Code** (см. ниже): пока Claude работает над задачей, Clawd сидит за ноутбуком
  и вслух рассказывает, что происходит («Правлю pet.js», мысли Claude в пересказе Haiku), зовёт,
  когда Claude ждёт твоего ответа, а когда задача готова — подпрыгивает и говорит, что проверить;
- **болтает репликами от Claude Haiku** — чаще и по делу: учитывает время суток, открытое окно,
  музыку, темп печати и простаивает ли пользователь; если ты давно ничего не делаешь, может
  подколоть («Стою тут уже 7 минут, как памятник»). Замечает, когда переключаешься на приложение.

- **с ним можно поговорить**: правый клик по Clawd (или «Поговорить с Clawd…» в трее) открывает
  поле ввода — пишешь, жмёшь Enter, он отвечает через Claude Haiku с учётом ситуации и предыдущих
  реплик; Esc или клик в другое окно — закрыть. Видит он только то, что ты написал в это поле.
- **умеет искать в интернете** (в чате Haiku может пользоваться веб-поиском и читать страницы);
- **выполняет команды в терминале по твоей просьбе** («убей процесс, который ест больше всего памяти»,
  «сколько места на диске»): Clawd показывает точную команду и запускает её **только после клика
  «Выполнить»** (по умолчанию в фокусе «Отмена», так что случайный Enter ничего не запустит),
  опасные команды подсвечены красным. Перед удалением или остановкой чего-либо он сперва
  предлагает команду, которая только показывает, что будет затронуто. Команды идут через `sh`
  на Linux и PowerShell на Windows, без `sudo`, с таймаутом 30 секунд; вывод Clawd пересказывает.

Меню в трее: «Позвать Clawd», «Поговорить с Clawd…», «Спрятать/Показать», «Слушать звук», «Видеть окна и печать»,
«Реплики через Claude (Haiku)», «Указать путь к claude…», «Связать с Claude Code»,
«Язык / Language» (русский или английский — и фразы Clawd, и реплики Haiku, и само меню), «Выход».
Все переключатели и язык запоминаются между запусками.

## Claude Code

Clawd ничего не просит настраивать вручную — нужен только установленный и залогиненный
[Claude Code](https://code.claude.com). Clawd ищет `claude` в `PATH`, в обычных местах установки
(нативный установщик, npm, nvm, volta, bun, pnpm, scoop, Claude Desktop), в `PATH` из реестра Windows
и через login-shell на Linux (на случай, если Clawd запущен ярлыком и не видит `.bashrc`/`.zshrc`).
Если не нашёл — при включении «Реплик через Claude» откроет окно выбора файла; путь можно сменить
пунктом «Указать путь к claude…» или переменной `CLAWD_CLAUDE_PATH`.

- **Реплики Haiku.** Clawd вызывает `claude -p --model haiku` в фоне, без инструментов, MCP и хуков,
  от твоего же аккаунта Claude Code — API-ключ не нужен. Запрос примерно раз в минуту-три, когда
  кончается запас фраз. Если `claude` не найден, Clawd говорит заготовленными фразами.
- **Связь с сессиями.** Пункт трея «Связать с Claude Code» добавляет в `~/.claude/settings.json`
  хуки `UserPromptSubmit`, `PreToolUse`, `Stop`, `Notification`, `SessionEnd` (остальные настройки
  не трогаются, рядом сохраняется `settings.json.clawd-backup`; повторный клик — удалить хуки).
  Хук отправляет событие через `curl` на `127.0.0.1:47823` с секретным токеном; если Clawd не
  запущен, хук просто молча ничего не делает. На Windows хуки Claude Code выполняются через Git Bash,
  `curl` там есть.

## Что Clawd видит

«Видеть окна и печать» — заголовок и имя приложения активного окна и **только число** нажатий
клавиш в минуту: какие именно клавиши нажаты, не сохраняется и никуда не уходит. Заголовок окна
и описание ситуации уходят в Claude Haiku, чтобы реплики были к месту, — если не хочется,
выключи пункт в трее. На Linux окна видны через X11 (под Wayland — только XWayland-приложения).

## Как устроено

- `src-tauri/` — Rust: прозрачное окно без рамки поверх всех окон, растянутое на рабочую
  область основного монитора. Всё окно пропускает клики насквозь; Rust опрашивает глобальную
  позицию курсора и отдаёт её во фронтенд, а фронтенд отключает «сквозные клики», только когда
  курсор над Clawd.
- `src-tauri/src/audio.rs` — захват того, что играет компьютер (WASAPI loopback на Windows,
  монитор звуковой карты PulseAudio/PipeWire на Linux) и простой анализ: громкие звуки,
  «играет музыка» (звук почти без пауз несколько секунд) и биты (всплески баса).
  Звук никуда не записывается и не отправляется.
- `src/` — фронтенд без сборщика (чистый JS-модуль): `sprite.js` рисует пиксельные кадры,
  `pet.js` — состояния и физика, `main.js` — отрисовка, мышь, связь с Rust.

## Запуск

Нужен Rust (stable) и системные зависимости Tauri:

- **Windows** — WebView2 (есть в Windows 10/11) и MSVC Build Tools.
- **Linux (Debian/Ubuntu)**:
  ```sh
  sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev libpulse-dev
  ```

Запуск для разработки:

```sh
cd src-tauri
cargo run
```

Фронтенд можно отлаживать и в обычном браузере: `python3 -m http.server -d src` и открыть
`http://localhost:8000` — без Tauri Clawd просто живёт во вкладке.

## Сборка установщиков

```sh
cargo install tauri-cli --version "^2" --locked
cd src-tauri
cargo tauri build
```

Результат — в `src-tauri/target/release/bundle/` (`.msi`/NSIS на Windows, `.deb`/`.rpm`/AppImage на Linux).

Иконки генерируются из спрайта: `python3 scripts/make_icons.py` (нужен Pillow).

## Ограничения

- **Wayland** не даёт приложениям ставить окна в произвольные координаты и читать глобальный
  курсор, поэтому на Wayland приложение само запускается через XWayland (`GDK_BACKEND=x11`).
- На Linux нужен композитор (в GNOME/KDE он есть всегда), иначе фон окна будет чёрным.
- Пока Clawd живёт только на основном мониторе.
- На Linux для звука нужен PulseAudio или PipeWire с `pipewire-pulse` (стоит по умолчанию почти везде).
- Музыка отличается от речи по признакам громкости и спектра (в речи постоянные провалы между
  слогами, у шума — «плоский» спектр), поэтому голосовые, подкасты и видео с разговором не
  заставляют Clawd танцевать. Музыка распознаётся примерно через 8 секунд после начала.
  Если он ошибается на каком-то звуке — запиши фрагмент и прогони
  `cargo run --example audio_probe -- clip.wav` в `src-tauri` (WAV 22050 Гц, моно, 16 бит).
- `CLAWD_DEBUG=1` печатает в консоль все события звука, окон и Claude Code.
